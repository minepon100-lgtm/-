# Wizardry Variants Daphne Offline 〜第一奈落〜

通信・課金なしで遊べる、オフライン専用の 3D ダンジョン RPG です。
「Wizardry Variants Daphne」をイメージした**非公式ファンメイド作品**です。キャラクター・ストーリー・グラフィックはすべてオリジナルで、画像ファイルは使っていません（SVG と Canvas で描画）。

**収録範囲：第一奈落（地下 1〜4 階）の一周目クリアまで**

## 遊び方

外部ライブラリもビルドも不要です。

- **いちばん簡単な方法**：`index.html` をブラウザで直接開く（`file://` のままで動きます）
- **ローカルサーバーで遊ぶ場合**：`npx http-server .` などで配信すると、Service Worker によって
  2 回目以降は完全にオフラインでも起動できます（PWA としてホーム画面にも追加できます）

セーブデータはブラウザの localStorage に自動保存されます。町の「記録」メニューから書き出し・読み込み（テキスト／ファイル）ができます。

### 操作

| キー | 動作 |
| --- | --- |
| W / ↑ | 前進 |
| S / ↓ | 後退 |
| A / ← ・ D / → | 左右を向く |
| Q / E | 左右に横移動 |
| M | 地図 |
| Space / Enter | 足元を調べる（階段・宝箱・門など） |

画面上のボタンでも操作でき、スマートフォンの縦画面にも対応しています。

## 原作からの主な変更点

### 1. オルグ石を廃止し、ゴールドに一本化
課金石（オルグ石）は存在しません。招来（ガチャ）を含むすべての支払いはゴールドで行います。

- 1 回招来：300 G ／ 10 回招来：3,000 G（★4 以上 1 体確定）
- 開始時の所持金は 5,000 G。ゴールドは戦闘・宝箱・売却で手に入ります

### 2. 主人公のキャラクタークリエイション
Wizardry 伝統の作成手順で主人公を作ります。

1. 名前・種族（人間／エルフ／ドワーフ／ノーム／ホビット）
2. 性格（善／中立／悪）：就ける職業に影響します
3. ボーナスポイントの振り分け（何度でも振り直せます。ごくまれに高いボーナスが出ます）
4. 職業（戦士／盗賊／魔術師／僧侶）：能力値と性格の条件を満たしたものだけ選べます
5. イメージカラー

主人公には専用スキル「奈落穿ち」があり、能力値も少し高めです。

### 3. 招来はすべてのキャラクターをピックアップに選べる
招来の間で、★3〜★5 の**全 17 キャラクターから自由にピックアップ対象を選べます**。

- 提供割合：★5 3% ／ ★4 15% ／ ★3 82%。ピックアップは同じレアリティの中で 50% の確率で選ばれます
- 招来 80 回で ★5 確定（天井）。招来ポイントが 100 たまると、ピックアップのキャラクターと交換できます
- 重複したキャラクターは「凸」になり、能力が +5% 上がります（最大 5 凸）。それ以上はゴールドに還元されます
- キャラクターごとの提供割合と招来履歴を確認できます

## ゲーム内容

- **町**：招来の間／宿屋／商店（奈落を深く潜るほど品揃えが増える）／寺院（蘇生・解毒）／編成／仲間一覧／記録
- **パーティ**：最大 6 人。前列 3 人が敵の直接攻撃を受けます。後列からの近接攻撃は、弓・槍以外だと威力が半分になります
- **奈落**：地下 4 階まで。ワイヤーフレーム風の 3D 視点、オートマップ、宝箱と罠（盗賊が解除できる）、回復の泉、施錠扉と鍵、階層ごとの強敵
- **戦闘**：ターン制コマンドバトル。スキル、状態異常（毒・睡眠）、強化、アイテム、逃走、オート、前ターンの繰り返しに対応
- **成長**：レベルアップで能力値が上がり、職業スキルを覚えます。★4・★5 のキャラクターは固有スキルを持っています
- **全滅**：救助隊に町へ運ばれ、所持金の 2 割を失います（主人公だけは無料で蘇生されます）
- **クリア後**：地下 4 階の門から、番人に何度でも再挑戦できます

## ファイル構成

```
index.html            エントリーポイント
css/style.css         スタイル
js/data.js            種族・職業・スキル・アイテム・敵・キャラクター・招来設定
js/maps.js            第一奈落のフロアマップ（地下1〜4階）
js/core.js            ゲーム状態・セーブ・能力値計算・成長
js/ui.js              画面切り替え・モーダル・肖像/敵グラフィック生成
js/creation.js        主人公キャラクタークリエイション
js/town.js            町の施設と共通メニュー
js/gacha.js           招来（ガチャ）
js/dungeon.js         3D ダンジョン探索
js/battle.js          戦闘
js/main.js            タイトル・起動
sw.js / manifest.webmanifest / icon.svg   オフライン対応（PWA）
tools/checkmaps.js    マップの到達可能性チェック
tools/smoke.js        ヘッドレスブラウザでの動作確認
tools/fullrun.js      自動プレイ bot によるクリアまでの通しテスト
```

### テスト

```sh
node tools/checkmaps.js                                   # マップ検証
NODE_PATH=$(npm root -g) node tools/smoke.js               # 主要画面の動作確認（要 Playwright）
NODE_PATH=$(npm root -g) node tools/fullrun.js             # キャラクリからエンディングまで自動プレイ
```
